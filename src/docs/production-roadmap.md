# Shadow Syndicate Production Roadmap

Current PvP is local/mock simulation only.

Future production requirements:
- Real accounts and cloud saves.
- Server-side PvP calculations.
- Anti-cheat checks and signed actions.
- Attack rate limits and cooldowns.
- Public player profiles.
- Leaderboards and seasons.
- Report/block tools.
- Name filter and content safety moderation.
- Backend database tables for players, profiles, saves, inventory, districts, attack logs, revenge events, bounties, seasons, alliances, and chat messages.
- Alliances/syndicates later.
- Real-time war events later.

Do not connect real backend PvP until the local economy, defense, revenge, and grudge systems feel fair.
