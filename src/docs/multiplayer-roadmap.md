# Shadow Syndicate Multiplayer Roadmap

## Phase A: Local Simulated PvP
Mock opponents, local attack results, revenge list, defense setup, bounties, grudge levels, and attack logs.

## Phase B: Account Login and Cloud Saves
Move local profiles into authenticated cloud saves while preserving existing local import/export backup.

## Phase C: Async PvP Attacks
Allow attacks against saved player profiles. Store attack result snapshots so users can see what happened while away.

## Phase D: Revenge and Bounty Sync
Sync revenge events, bounty progress, retaliation bonuses, and grudge history between players.

## Phase E: Seasons and Leaderboards
Season resets, ranked rewards, citywide leaderboards, and limited-time events.

## Phase F: Alliances or Syndicates
Player groups, shared objectives, alliance wars, help requests, and territory pressure.

## Phase G: Real-Time War Events
Optional live war windows, real-time conflict feeds, and timed crew actions.
